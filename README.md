# Happiest Countries in the World – Data Analysis (Python & Pandas)

This project explores which countries are the happiest in the world and how happiness has changed over time.  
The analysis uses publicly available data and focuses on understanding how factors like income and life expectancy relate to overall happiness.

The goal of this project is to practice real-world data analysis skills using Python and Pandas and present the results through clear visualizations.

---

## What this project does

- Ranks countries based on happiness scores (Cantril Ladder)
- Compares happiness levels across different years
- Identifies countries that improved or declined the most
- Examines the relationship between:
  - Happiness and GDP per capita
  - Happiness and life expectancy
- Creates visualizations that summarize key insights

---

## Data sources

All data is loaded directly from **Our World in Data**, which compiles information from the World Happiness Report and related sources.

Main dataset:
- Happiness (Cantril Ladder):  
  https://ourworldindata.org/grapher/happiness-cantril-ladder.csv

Additional datasets used for comparison:
- GDP vs Happiness  
- Life Expectancy vs Happiness  

These datasets are accessed using their public CSV links.

## Visualizations included

The project produces the following charts:

- Top 10 happiest countries (latest year)
- Countries with the biggest improvement in happiness over time
- Happiness vs GDP per capita (scatter plot)
- Happiness vs life expectancy (scatter plot)
- Happiness trends over time for selected countries

All charts are generated using Matplotlib and saved locally.

---

Key takeaways

Nordic countries consistently rank among the happiest

Higher income generally correlates with higher happiness, but not perfectly

Life expectancy also shows a positive relationship with happiness

Some countries outperform expectations despite lower GDP levels
